# Multiple Linear Regression - Insurance Cost Prediction

## About the Project

This project implements Multiple Linear Regression using an insurance dataset.

The goal is to understand the complete Machine Learning workflow, from data preprocessing and exploratory data analysis to model training and evaluation.

## Dataset

- Rows: 1,338
- Columns: 13
- Target: Charges

## Workflow

- Data understanding
- Missing value handling
- Exploratory Data Analysis (EDA)
- Duplicate checking
- Outlier detection using IQR
- Multicollinearity analysis using VIF
- Feature selection
- Train-test split
- Multiple Linear Regression
- Predictions
- Model evaluation

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook / Google Colab

## Model Result

R² Score: 0.8436 (~84.36%)
